# 🛢️ Vehicle Engine Oil Inspection Tool

A professional 7-step digital inspection app for auto technicians.
Built for real shop use — captures customer info, 360° vehicle photos,
oil condition analysis, and generates service recommendations automatically.

## Features
- VIN decoder with live lookup
- 360° before & after photo documentation (liability protection)
- Interactive dipstick oil level visualizer
- Oil color/condition analyzer with auto-diagnosis
- Pass / Monitor / Service Now status system
- 7-step guided inspection: Oil, Dipstick, Filter, Engine Bay, Leak check

## Tech Used
React · Vite · JavaScript · CSS · Claude Vision AI
- 📷 Camera odometer capture with Claude Vision AI
